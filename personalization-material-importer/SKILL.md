# Personalization Material Importer

## 使用场景

当用户提供腾讯文档链接，要求复制某个学生的“个性化素材”，或写 PS 前发现 `Personalization_Materials/` 为空、缺失、只有模板内容时使用。

## 输出位置

保存到学生目录下：

```text
Personalization_Materials/
```

推荐文件名：

```text
个性化素材-来源.md
个性化素材补写候选.md
```

本 skill 输出资料源文件，不是成稿，因此文件名不强制使用 `Vn`。
文件名不得添加日期前缀；同名来源需要保留多个版本时，在来源 key 后使用 `Vn`，或按“保留并更新”规则维护同一文件。

## 必读资料

1. 用户提供的腾讯文档链接或原文。
2. `Basic_Info/*.md`
3. `Course_Info/*.md`
4. `Resume/*.md`
5. `Personalization_Info/*.md`
6. `Student_Profile/学生偏好总结.md`
7. 用户提供的申请学校、专业、方向或项目要求。

如果导入正文提到附件文件名，必须查找或导出附件到 `Additional_Documents/` 并生成同名 `.md`；无法取得附件时，在素材文件中列为缺失输入。

## 导入流程

1. 确认学生姓名和目标学生目录。
2. 读取腾讯文档链接内容；优先使用已配置的 Tencent Docs MCP/CLI，无法读取时说明需要用户粘贴正文或开放权限。
3. 将正文整理为 Markdown，保留原始字段含义，不追求排版复刻。
4. 保存到 `Personalization_Materials/`，并标注来源链接、导入时间、是否完整。
5. 若已有同名或同主题 Markdown，不粗暴覆盖；新建日期文件，或在更新前备份旧文件。

## 标准结构

导入或补写后的 Markdown 尽量使用以下结构：

```md
# 个性化素材

## 文件信息

- 学生：
- 来源：
- 整理时间：
- 完整性：

## 已确认事实

-

## 个人动机与兴趣线索

-

## 经历反思与能力证据

-

## 职业规划线索

-

## 申请专业/项目匹配线索

-

## 合理推断/表达方向

-

## 待确认问题

-
```

## 缺失素材时的补写规则

如果 `Personalization_Materials/` 为空或内容不足，可以生成 `个性化素材补写候选`，但必须遵守：

- 只基于已读取资料和申请目标进行主题提炼、动机延展、能力迁移和问题清单整理。
- 可以写“可表达为”“可作为主线”“可进一步确认”的候选方向。
- 不得编造具体经历、课程、成绩、奖项、公司、项目成果、时间、地点、数据或学校项目信息。
- 未在资料中出现但可能需要补充的内容，放入 `待确认问题`，不要写进 `已确认事实`。
- 如果关键输入不足以形成 PS 主线，应返回 `Blocked`，列出需要用户补充的问题。

## 与学生偏好的冲突处理

- `Student_Profile/学生偏好总结.md` 只用于语气、详略、措辞偏好和长期修改习惯。
- `Personalization_Materials/` 用于 PS 内容依据、动机线索和经历反思。
- 事实冲突时，以可追溯原始资料和用户最新明确输入为准；无法判断则列为 `待确认问题`。
- 风格冲突时，以学生偏好总结为准，但不改变事实内容。

## 给 PS 的使用边界

个人陈述可以使用：

- `已确认事实` 中可追溯的经历和信息。
- `个人动机与兴趣线索`、`经历反思与能力证据`、`职业规划线索` 中有资料依据的内容。
- `合理推断/表达方向` 中不涉及新增事实的概括性主线。

个人陈述不得使用：

- `待确认问题` 中尚未确认的内容。
- 任何没有资料依据的具体事实。
- 为了增强说服力而补出的量化结果、奖项、课程名、教授名或项目名。

## 阻塞条件

- 腾讯文档无法读取，且用户未提供正文或截图内容。
- 学生基础资料、课程资料和简历资料都不足，无法生成安全的补写候选。
- 用户要求将未经确认的内容写成确定事实。
- 导入材料与基础资料存在关键事实冲突，且无法判断可信来源。

## 最小输出

- `Personalization_Materials/` 下的导入 Markdown 或补写候选 Markdown。
- 文件中必须区分 `已确认事实`、`合理推断/表达方向` 和 `待确认问题`。
- 如果无法继续，输出阻塞原因和需要用户补充的问题。
