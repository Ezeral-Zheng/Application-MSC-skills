# 个人陈述八维评分与校准标准

本标准供上下文隔离的 `external-application-review` 使用。前七维用于 `single-draft`，第八维“跨申请结构独立性与相似度”用于同一学生存在多个申请目标时的 `portfolio-differentiation`。`application-review` 继续负责事实与合规，不使用本评分代替事实核查。

## 提交门禁

前七项单篇维度各 10 分，保留一位小数，平均分按算术平均计算并保留一位小数；组合审稿再对第八维单独评分。只有同时满足以下条件才可判定 `Pass`：

- `single-draft` 前七维平均分不低于 `8.5`；有组合输入时，第八维也必须不低于 `8.5`。
- 不存在 `P0 / Must Fix`。
- 不存在值得继续生成新候选稿的 `P1 / Should Fix`。
- 课程堆砌检查通过。
- 当前候选稿此前已通过 `application-review`。
- `portfolio-differentiation` 的矩阵四层约束审计全部为 `Pass`，且已提供逐篇结构签名和全文结构风险证据。

平均分代表当前文本质量，不代表录取概率。分数不能覆盖明确问题：即使平均分达到 8.5，只要存在 P0，状态仍为 `Revise` 或 `Blocked`。

## 评分校准

每个维度必须引用原文证据并解释扣分原因，不得凭整体感觉给分。

| 分数 | 校准含义 |
|---:|---|
| 9.0–10.0 | 论证成熟，证据充分，只有不值得生成新版本的微小优化 |
| 8.5–8.9 | 达到提交门槛，没有实质性必须修改问题 |
| 8.0–8.4 | 接近提交标准，但仍有至少一个明确影响说服力的问题 |
| 7.0–7.9 | 需要实质性修改，部分链路依赖读者自行补足 |
| 6.0–6.9 | 建议重构部分内容或结构 |
| 6.0以下 | 申请论证尚未成立，需要重新设计核心链路 |

不得为了把平均分凑到阈值而人为调分。每轮审稿人只解释当前稿各维度得分，不接收或解释相邻轮次分数变化；跨轮趋势只由主控 Agent 在过程临时目录中机械汇总，不得反馈给下一轮审稿人。

## 八个维度

### 1. 逻辑结构

检查开头、段落功能、因果推进、重复、逻辑跳跃、能力缺口、结尾收束。高分稿件能用真实证据清楚解释学习选择与职业方向；成果深化、方法迁移、能力整合、职业延伸及未解问题均可形成主线，不要求每段经历以局限收尾或遵循固定顺序。

### 2. 经历与专业匹配

检查经历是否涉及目标专业的真实问题，申请人的个人行动、方法和判断是否清楚，经历是否自然导出进一步学习需要。仅加入专业关键词、技术名词或课程名称不能获得高分。

### 3. 语言表达

检查语法、搭配、中式英语、句长、抽象名词、被动语态、重复句式、AI痕迹、动作动词和包装强度。语言应准确自然，强度不得超过事实证据。阅读全文，检查主句骨架、主从安排、信息焦点、具体对象承接及跨段节奏；句句有不同事实仍可能因相同骨架长期平铺而单调。These/I/which、简单句或同一从句的频率不直接决定得分。跨段单调明显削弱信息重点或说服力、可安全重组时，应按 P1 / Should Fix 处理，不因语法正确而放行；纯措辞偏好仍为 P2。扣分须有具体跨段语境与读者影响，验收看信息层级与阅读节奏，不以换词或增加复杂句数量替代。报告须有覆盖每段的全文表达覆盖表，即使 Pass 也不省略。

时间表达也按全文信息作用判断：不以个人年月、预计毕业或年级列表代替论证，不将其统一改成 During my ... year；保留必要先后、暑期边界、跨年持续和计划语气。名称中的年份、数据年份、必要时长和题目明确要求不自动扣分。具体年级换算留给事实门禁；盲审只报告正文可见的重复、歧义或疑似矛盾，不读取校历/写作映射或自行推定事实。

### 4. 个人辨识度

检查读者能否形成具体申请人印象，是否看见个人贡献、判断方式、认知变化和可记忆细节。团队成果不得个人化，通用优秀品质不能代替真实辨识度。

### 5. 动机说服力

检查学习需求是否由真实经历、成果、判断、已明确的兴趣或合理职业延伸支持。成果深化、方法迁移、能力整合和未解问题均可成立，不强制“尝试解决→发现能力边界→产生深造需求”。行业趋势、就业前景和笼统兴趣不能单独支撑高分。

### 6. 学校与项目匹配

检查具体学习需求、项目资源与未来用途的对应，项目内容是否具体且不可直接替换学校名称。通常只展开 2–3 项最相关资源，不以官网课程清单代替论证。

### 7. 职业规划

检查短期方向、长期递进、希望解决的问题、所需能力及其与目标专业的关系。职业目标须与前文经历、能力、判断或已明确的兴趣有可解释的联系，不得罗列多个缺少统一逻辑的岗位。

### 8. 跨申请结构独立性与相似度

该维度只判断同一学生多篇 PS 的全文结构是否真正独立，不把不同专业名称、课程名或低词面相似度误认为差异化。审稿人必须读取当前候选稿、其他目标最新正式 PS、叙事矩阵和相似度工具报告，抽取每篇的结构签名：开头原型、段落功能序列、核心证据职责、能力缺口位置、职业目标生成路径、Why Program 的主要功能和结尾姿态。

至少完成以下检查：

- 开头是否共享同一非中性模板族，例如“兴趣始于问题”“异常暴露边界”“某次实习让我意识到”等。
- 段落数、段落职责和证据顺序是否形成可替换的同一槽位骨架。
- GPA/学术背景、职业目标和 Why Program 是否在所有稿件中固定占据相同位置和相近篇幅。
- 同一经历是否重复完整的背景—方法—结果—反思行动链，只在结尾换专业标签。
- 结尾是否反复使用同一能力缺口、同一项目下一步和同一承诺动作。
- 相邻目标是否至少改变以下六项中的两项：因果入口、素材取舍、经历职责、能力缺口位置、职业目标生成路径、结尾姿态。

评分校准：

- `9.0–10.0`：每个近邻目标均有清楚的结构签名，至少改变两项关键结构变量；无完整非事实句、行动链或结尾模板复用。
- `8.5–8.9`：仅共享必要硬事实，段落功能和结尾论证独立；少量词面或通用连接句不影响结构。
- `8.0–8.4`：存在一个同构结构族、固定段落槽位或模板化结尾，需重新分配证据或改变因果路径。
- `7.0–7.9`：多个近邻目标共享同一开头—证据—能力缺口—项目收束骨架，或同一经历完整行动链重复。
- `6.9及以下`：不同目标基本是同一底稿，仅替换专业/课程/职业名称，组合审稿必须 `Revise`。

第八维不采用纯词面阈值代替人工判断。工具中的 `structural_similarity`、`opening_template_family_overlap`、`rhetorical_signature`、`experience_passage_similarity` 只提供定位证据；只要正文结构、叙事动作或结尾姿态同构，即使 Jaccard 较低，也不得判 `Pass`。

## 问题等级映射

| 内容等级 | 执行标签 | 规则 |
|---|---|---|
| `P0` | `Must Fix` | 核心论证不成立、个人贡献缺失、动机断裂、项目匹配失真等，必须修改 |
| `P1` | `Should Fix` | 明显限制说服力，默认建议采纳 |
| `P2` | `Optional` | 主要影响完成度或阅读体验，默认不触发新候选稿 |
| `Needs Confirmation` | 事实状态 | 与 P0/P1/P2 正交；需要新事实时不得自动修改 |
| `Do Not Change` | 保护项 | 修改worker必须保留 |

若 P0 改善依赖新事实，状态为 `Blocked`，而不是自动补写。

## 证据链检查

按论证需要识别核心经历中实际存在的要素，不作为每段必填槽位：

- 经历事实。
- 申请人个人行动。
- 项目结果或反馈。
- 个人认知变化。
- 进一步学习需求（深化、迁移、整合或补足能力）。
- 对目标项目和职业的连接。

若项目介绍后直接宣告宏观认知，却缺乏支撑判断所需的个人行动或证据，应在相应维度说明影响；不能仅因某项经历没有认知转折、失败或能力缺口而扣分。没有结果事实时可以建议确认或调整论证，不得要求编造结果。

## 结构与逐段诊断

先以“一段一功能”概括原结构，再判断问题程度。推荐结构必须根据当前素材设计，不得默认套用八段式或任何固定顺序。

`Revise` 报告必须提供紧凑的逐段表：

| 段落 | 当前功能 | 主要问题 | 修改动作 | 修改后功能 |
|---|---|---|---|---|

`Pass` 报告无需为了形式逐段挑错，但仍需给出结构签名和 `Do Not Change`。

## 单个问题字段

每个 P0/P1 问题必须包含：

- 稳定问题 ID。
- 问题等级与执行标签。
- 所属评分维度。
- 原文定位与最短必要引文。
- 问题原因及对读者的影响。
- 修改目标与具体动作。
- 事实边界与必须保留内容。
- 是否需要确认。
- 验收标准。

修改示例只在能够完全基于原文改写时提供；示例不是要求逐字采用的替换文本。

## 输出结果

最终结论映射：

| 条件 | 状态 |
|---|---|
| 平均分≥8.5，且无P0、无值得修改的P1 | `Pass` |
| 平均分<8.5，或存在可安全修复的P0/P1 | `Revise` |
| 核心改善依赖缺失或待确认事实 | `Blocked` |

报告必须准确列出前七项得分、前七维平均分；有组合输入时还必须列出第八维得分、结构风险证据和组合门禁判断。`single-draft` 没有组合输入时，第八维写 `N/A`，不得虚构跨申请结论。
