# 个人陈述五维质量标准

本文件用于 Personal Statement / SOP 的写作阶段自查，提供非量化质量边界，不得用笼统的“整体不错”代替。它不参与 `application-review` 的事实门禁状态判断；事实真实性由 `application-review` 兜底，上下文隔离的内容审稿按 `个人陈述八维评分与校准标准.md` 评分。

## 1. 英文语言质量

目标：英文准确、地道、自然、成熟，像真实申请人经过专业编辑后的表达，而不是中文逐字翻译或 AI 堆砌。

通过标准：

- 无语法、拼写、标点、时态、单复数、冠词、介词和主谓一致错误。
- 搭配符合英语习惯，动词具体准确；避免中式表达、机械翻译和不必要的名词化。
- 全文句式与信息组织有层次：主要判断、背景和条件通过主从安排、具体对象承接及有职责的长短句清楚推进，不长期以 I + 行动/感悟/hope 平铺。准确的简单句可保留，但每句信息不同不代表全文已经丰富；不设高级句配额，也不强制减少 I。
- 以完整文章检查经历、学习意向、项目匹配与职业段，不能只看几个漂亮句子或换过的开头。内容门禁中，跨段单一骨架明显削弱重点与节奏且可安全改善时，应列 Should Fix；纯措辞偏好仍为 Optional。
- 具体对象、行动或判断自然承接；检查重复的句首、抽象感悟和动机宣告，不能只替换 these/this/such 或 led/prompted/inspired。重复的词不是自动错误，须判断指代清晰度、信息增量和读者影响。
- 衔接自然，不依赖 `Firstly`、`Moreover`、`Furthermore` 等机械连接词。
- 语气自信但克制，避免夸张、自我吹捧、套话和过度润色。
- 中文对照稿与英文事实、范围和语气强度一致。
- PS 时间定位服务论证：默认省略无必要的个人年月及预计毕业信息，年级不是每段必填槽位；不要把固定日期开头改成固定 During my ... year。暑期、跨学年及未来计划须表达清楚。正式名称/数据年份、必要时长和明确要求的日期可保留。年级换算由事实审查核实，内容盲审不读取来源包、不猜年级。

常见问题：语法错误；中式搭配；空泛动词；套话；句型重复；过长句；AI 腔；英文与中文事实不一致。

## 2. 结构与逻辑主线

目标：全文能用一句话概括，段落按因果关系推进，而不是简历式经历拼接。

通过标准：

- 开头尽快进入真实问题、观察、选择或兴趣来源。
- 每段承担不同功能，并推进同一申请主线。
- 经历之间体现兴趣、行动、认识和能力的递进。
- 职业目标自然导出学习需求，Why Program 是前文逻辑的结果。
- 应届生应覆盖本科专业选择原因、本科经历、职业规划和硕士专业/学校选择原因四项信息责任；按本篇论证组织，不强制固定顺序。
- 四项是逻辑阶段而非固定段落模板；不同申请目标应允许不同的开头、段落划分和经历推进方式。
- 结尾完成收束，不重复全文或喊口号。

常见问题：时间线堆砌；段落功能重复；转专业缺少解释；职业规划突然转向；Why Program 与前文脱节；开头和结尾重复。

## 3. 素材、细节与反思深度

目标：用少量真实经历证明能力、判断和成长，不把 PS 写成项目报告。

通过标准：

- 只选择服务申请主线的核心经历，不追求覆盖全部简历。
- 经历说明问题、行动、选择理由、结果、反思或能力迁移中的关键环节。
- 明确申请人的个人贡献，同时准确保留团队成果边界。
- 方法、工具、数据和奖项用于支撑判断，不形成清单。
- 不只写“做了什么”，还写“为什么这样做、因此如何改变后续选择”。
- 所有新增事实均有依据；没有素材时不得虚构冲突、领导行为或成果。

常见问题：项目摘要；工具罗列；只有结果没有判断；泛称提升沟通/团队/领导力；团队成果个人化；数据过多挤压反思。

## 4. 专业与项目匹配度

目标：建立经历与能力、具体学习需求、项目资源和未来用途的联系。需求可以来自成果深化、方法迁移、新场景应用、能力整合、职业延伸或补足能力；不要求每段都暴露局限。

通过标准：

- Why Program 说明申请人具体希望深化、迁移、整合或补足什么，以及项目资源如何回应；信息顺序服从论证。
- 通常只展开 2–3 项最相关课程或资源，而非罗列官网内容。
- 每项课程或资源都连接具体经历、具体学习需求和未来用途。
- 区分“感兴趣”与“真正需要”，说明项目为何是当前阶段的合理下一步。
- 学校、课程、教授、实验室和项目特色均可核实。
- 多校文书不能只替换学校名和课程名。
- 同一学生申请不同专业时，目标专业应改变全文的核心问题、素材排序、经历解释或能力缺口，不能只改变最后的 Why Program。

常见问题：课程清单；复制官网；通用赞美；课程与经历无关；只说课程有趣；编造行业合作、就业资源或研究机会。

### 强制判断项：申请专业课程堆砌

必须单独执行“课程堆砌检查”，不能只凭整体阅读印象判断：

1. 统计 Why Program / Why Major 部分明确写出的课程名称数量。
2. 检查课程名称是否连续出现，或是否占据该部分过多篇幅。
3. 检查每门保留课程是否完成“既有经历—具体学习需求—课程价值—未来应用”的连接。
4. 检查删除课程名称后，该段是否仍有清楚的项目匹配逻辑。

默认规则：

- 通常最多展开 2–3 门最相关课程或等价项目资源。
- 出现 4 门及以上具名课程时，默认判定存在课程堆砌，至少生成一个 `Should Fix`；只有学校题目明确要求讨论多门课程，且每门课程都有实质关联分析时才可例外。
- 即使只有 2–3 门课程，只要连续罗列名称、课程名称占据 Why Program 主要篇幅，或缺少与经历和具体学习需求的连接，仍判定为课程堆砌。
- 课程堆砌问题未消除时，“专业与项目匹配度”不得标记为 `Pass`，整篇独立内容审稿也不得标记为 `Pass`。

修复时优先删除弱相关课程，保留最能回应学习需求的 2–3 项资源；不得仅把课程列表换成更隐蔽的长句列表。

## 5. 个人辨识度与申请说服力

目标：读者能够记住、理解并相信这个申请人，知道为什么是此人、此专业和此时。

通过标准：

- 能用一句话概括申请人的独特定位或能力组合。
- 至少有一个具有辨识度的真实观察、经历或核心判断。
- 个性来自选择和思考方式，不依赖形容词、自我评价或戏剧化包装。
- 职业目标具体到足以支撑学习选择，但不超出现有事实。
- 申请动机来自个人经历，而不只来自行业趋势和学校声誉。
- 语言、素材选择和详略符合学生偏好与真实背景。

常见问题：换名字仍成立；方向过多；全靠形容词塑造人设；通用行业趋势；夸张故事；语言流畅但没有个人判断。

## 跨申请组合差异

当同一学生存在多个目标项目 PS 时，单篇五维通过后仍需横向检查：

- 首段是否复用完整的非事实句或相同切入方式。
- 前两至三段是否使用相同经历顺序和相同能力结论。
- 同一项目是否在不同文书中承担不同论证功能。
- 目标专业是否影响职业问题、能力缺口和全文叙事，而非只影响末段课程名称。
- `PS_申请组合叙事矩阵.md` 是否与正文一致。
- 每篇的段落功能签名是否不同，还是只在固定槽位中替换经历。
- 是否所有稿件都固定使用学术背景段、职业规划段和 Why Program 末段。
- 相邻专业是否至少改变因果入口、素材取舍、经历职责、能力缺口位置、职业路径或结尾方式中的两项。
- 是否有主动舍弃素材，而不是默认把主经历和辅助经历全部装入正文。
- 同一经历在不同 PS 中是否仍复用相同事实组合、行动链、约束和反思结论。
- 经历段差异是否来自真实语义增量，而不是字数、句序、同义词或专业标签变化。
- 各经历段是否被平均分配为相近篇幅并使用相同内部结构。

机械相似度只用于预警。最终判定以叙事功能为准，不要求隐藏必要硬事实，也不鼓励无意义的同义改写。

## 维度判定

写作阶段自查时，每个维度可以标记：

- `Pass`：无影响交付的实质问题。
- `Needs Fix`：至少一个可用现有文本安全修复的 `Must Fix` 或 `Should Fix`。
- `Needs Confirmation`：关键改善依赖学生补充或确认事实。
- `Blocked`：该维度存在关键缺失或矛盾，继续写会导致编造。

本文件本身不得给数字分数；必须用问题 ID 连接维度结论和具体证据。这里的 `Needs Fix` 只表示写作自查尚未完成，不得直接成为 `application-review` 的事实审查状态或触发事实修订 `Rn`。`external-application-review` 的隔离内容审稿应使用八维校准标准给分；第八维仅在存在多个申请目标时评分，三者用途不同，不得混用。
