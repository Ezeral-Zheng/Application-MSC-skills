# 个人陈述五维质量标准

审查 Personal Statement / SOP 时必须逐维检查，不得用笼统的“整体不错”代替。五个维度共同决定是否值得交付；事实真实性仍由 `application-review` 兜底。

## 1. 英文语言质量

目标：英文准确、地道、自然、成熟，像真实申请人经过专业编辑后的表达，而不是中文逐字翻译或 AI 堆砌。

通过标准：

- 无语法、拼写、标点、时态、单复数、冠词、介词和主谓一致错误。
- 搭配符合英语习惯，动词具体准确；避免中式表达、机械翻译和不必要的名词化。
- 句式长短有变化，复杂句可读，不以生僻词或长句冒充成熟。
- 衔接自然，不依赖 `Firstly`、`Moreover`、`Furthermore` 等机械连接词。
- 语气自信但克制，避免夸张、自我吹捧、套话和过度润色。
- 中文对照稿与英文事实、范围和语气强度一致。

常见问题：语法错误；中式搭配；空泛动词；套话；句型重复；过长句；AI 腔；英文与中文事实不一致。

## 2. 结构与逻辑主线

目标：全文能用一句话概括，段落按因果关系推进，而不是简历式经历拼接。

通过标准：

- 开头尽快进入真实问题、观察、选择或兴趣来源。
- 每段承担不同功能，并推进同一申请主线。
- 经历之间体现兴趣、行动、认识和能力的递进。
- 职业目标自然导出学习需求，Why Program 是前文逻辑的结果。
- 应届生默认保持“本科专业选择原因—本科经历—职业规划—硕士专业/学校选择原因”的大顺序。
- 结尾完成收束，不重复全文或喊口号。

常见问题：时间线堆砌；段落功能重复；转专业缺少解释；职业规划突然转向；Why Program 与前文脱节；开头和结尾重复。

## 3. 素材、细节与反思深度

目标：用少量真实经历证明能力、判断和成长，不把 PS 写成项目报告。

通过标准：

- 只选择服务申请主线的核心经历，不追求覆盖全部简历。
- 经历说明问题、行动、选择理由、结果、反思或能力迁移中的关键环节。
- 明确申请人的个人贡献，同时准确保留团队成果边界。
- 方法、工具、数据和奖项用于支撑判断，不形成清单。
- 不只写“做了什么”，还写“为什么这样做、因此如何改变后续选择”。
- 所有新增事实均有依据；没有素材时不得虚构冲突、领导行为或成果。

常见问题：项目摘要；工具罗列；只有结果没有判断；泛称提升沟通/团队/领导力；团队成果个人化；数据过多挤压反思。

## 4. 专业与项目匹配度

目标：建立“过去经历—当前能力—能力缺口—项目资源—未来应用”的具体关系。

通过标准：

- Why Program 先说明申请人需要补足什么，再选择项目资源回应。
- 通常只展开 2–3 项最相关课程或资源，而非罗列官网内容。
- 每项课程或资源都连接具体经历、能力缺口和未来用途。
- 区分“感兴趣”与“真正需要”，说明项目为何是当前阶段的合理下一步。
- 学校、课程、教授、实验室和项目特色均可核实。
- 多校文书不能只替换学校名和课程名。

常见问题：课程清单；复制官网；通用赞美；课程与经历无关；只说课程有趣；编造行业合作、就业资源或研究机会。

### 强制判断项：申请专业课程堆砌

必须单独执行“课程堆砌检查”，不能只凭整体阅读印象判断：

1. 统计 Why Program / Why Major 部分明确写出的课程名称数量。
2. 检查课程名称是否连续出现，或是否占据该部分过多篇幅。
3. 检查每门保留课程是否完成“既有经历—能力缺口—课程价值—未来应用”的连接。
4. 检查删除课程名称后，该段是否仍有清楚的项目匹配逻辑。

默认规则：

- 通常最多展开 2–3 门最相关课程或等价项目资源。
- 出现 4 门及以上具名课程时，默认判定存在课程堆砌，至少生成一个 `Should Fix`；只有学校题目明确要求讨论多门课程，且每门课程都有实质关联分析时才可例外。
- 即使只有 2–3 门课程，只要连续罗列名称、课程名称占据 Why Program 主要篇幅，或缺少与经历和能力缺口的连接，仍判定为课程堆砌。
- 课程堆砌问题未消除时，“专业与项目匹配度”不得标记为 `Pass`，整篇独立内容审稿也不得标记为 `Pass`。

修复时优先删除弱相关课程，保留最能回应能力缺口的 2–3 项资源；不得仅把课程列表换成更隐蔽的长句列表。

## 5. 个人辨识度与申请说服力

目标：读者能够记住、理解并相信这个申请人，知道为什么是此人、此专业和此时。

通过标准：

- 能用一句话概括申请人的独特定位或能力组合。
- 至少有一个具有辨识度的真实观察、经历或核心判断。
- 个性来自选择和思考方式，不依赖形容词、自我评价或戏剧化包装。
- 职业目标具体到足以支撑学习选择，但不超出现有事实。
- 申请动机来自个人经历，而不只来自行业趋势和学校声誉。
- 语言、素材选择和详略符合学生偏好与真实背景。

常见问题：换名字仍成立；方向过多；全靠形容词塑造人设；通用行业趋势；夸张故事；语言流畅但没有个人判断。

## 维度判定

每个维度只能标记：

- `Pass`：无影响交付的实质问题。
- `Needs Fix`：至少一个可用现有文本安全修复的 `Must Fix` 或 `Should Fix`。
- `Needs Confirmation`：关键改善依赖学生补充或确认事实。
- `Blocked`：该维度存在关键缺失或矛盾，继续写会导致编造。

不得给数字分数制造虚假精确性。必须用问题 ID 连接维度结论和具体证据。
