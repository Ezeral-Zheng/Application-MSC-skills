# Student Style Memory

## 使用场景

当完成文书修改、用户明确总结偏好、或写作前需要读取学生长期风格偏好时使用。

## 记忆文件

每个学生目录下维护：

`Student_Profile/学生偏好总结.md`

## 参考资料

- 本 skill 的参考文档放在 `Application_System/skills/student-style-memory/references/`。
- 可放偏好总结样例、风格标签说明、反馈归类规则、禁用表达沉淀规则等。
- 更新偏好前如参考目录中有与当前反馈类型或文书类型相关的文件，应优先读取相关文件；不要无差别读取全部参考资料。

## 记忆结构

文件应包含：

- 稳定偏好
- 待观察偏好
- 推荐信偏好
- 个人陈述偏好
- 简历偏好
- 禁用或慎用表达
- 常用核心素材
- 历次修改摘要

## 更新规则

- 修改后自动更新。
- 明确、重复或强烈反馈写入“稳定偏好”。
- 单次、模糊或可能只针对某篇文书的反馈写入“待观察偏好”。
- 不把一次偶然意见泛化到所有文书类型。
- 保留日期、文书类型和反馈来源，方便回溯。
- 只记录学生个人偏好、风格偏好、素材偏好和禁用表达。
- 不记录审查发现的事实错误、版本问题、素材混用、模板残留、结构错误或流程错误；这些内容写入 `Review_Memory/审查问题记忆.md`。

## 写作前使用

写作或修改前先读取学生偏好总结，并遵守：

- 禁用表达优先级最高。
- 文书类型偏好优先于通用偏好。
- 待观察偏好作为参考，不作为硬规则。
