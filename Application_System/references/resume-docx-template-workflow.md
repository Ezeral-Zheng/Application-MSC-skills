# Resume DOCX Template Workflow

## 定位

本文件定义完整简历从正式 Markdown 到参考 Word 样式 DOCX 的导出流程。Markdown 是事实和版本的唯一正式来源；DOCX 是可选呈现层，不参与 Resume 版本递增、版本索引或内容审查历史。

## 流程

```text
资料标准化
  → Resume-Experience 全量整理
  → 目标专业能力映射与经历筛选
  → 专业版 Resume Markdown
  → application-review / 独立内容审稿
  → Word 模板映射
  → render_docx.py 页面渲染
  → 逐页视觉检查
  → 仅调整版式并重新渲染
  → 交付 Markdown；按需附带 DOCX
```

## 示例参考模板的版式令牌

- 页面：A4 纵向；四边约 1.27 cm。
- 字体：中文正文优先楷体；英文和数字跟随参考文件中的字体映射；导出前检查目标环境是否缺字，并设置可接受的字体回退。
- 姓名：居中、加粗、约 22 pt。
- 联系方式：居中、约 10 pt。
- 正文：约 10 pt；公司、学校、项目名称加粗；职位、项目副标题可用斜体。
- 结构：使用四列布局表达“主体 / 角色或描述 / 辅助信息 / 日期”；通过合并单元格实现模块标题和多行 bullet。
- 分隔：教育、实习、项目、个人介绍等一级模块之间使用细横线。
- 日期：固定右对齐，避免用连续空格模拟。
- 内容：每条 bullet 保持动作—方法—结果结构；不得为了塞入一页而删除事实依据或压缩到不可读字号。

## DOCX 实现要求

当前可使用：

```bash
python3 Application_System/tools/export_resume_docx.py \
  '<学生>/Resume/<专业版 Resume-Vn.md>' \
  '<任务临时目录>/<学生>-Resume-Vn.docx' \
  --render
```

该工具支持 `#` 学生姓名、`Contact:` 联系方式、`##` 模块标题、`**经历名称** | *副标题*` 经历标题、日期行和 `-` bullet。复杂或非标准 Markdown 先整理为标准 Resume 结构，再导出。

- 使用真实表格、明确列宽和段落格式，不依赖连续空格。
- 隐藏不需要的表格边框，只保留模板要求的分隔线。
- 所有列宽、单元格边距、字号、行距和段前段后间距显式设置。
- 允许自然分页；禁止固定行高导致文字裁切。
- 发现第二页只有少量残留内容时，优先调整内容密度、段前段后间距和列宽，再考虑轻微字号调整。
- 不得通过删减、改写或虚构内容解决分页问题。

## QA 清单

- [ ] Markdown 与 DOCX 文本逐项一致。
- [ ] 页面尺寸、边距、字体和字号符合模板。
- [ ] 姓名、联系方式和模块标题位置稳定。
- [ ] 日期全部右对齐且不漂移。
- [ ] 横线不穿过文字，表格无可见边框残留。
- [ ] bullet 不被截断、不重叠、不出现异常换行。
- [ ] 不出现孤立标题、孤立日期或只含一两行的异常末页。
- [ ] 在目标 Word/LibreOffice 环境渲染后再次检查。
