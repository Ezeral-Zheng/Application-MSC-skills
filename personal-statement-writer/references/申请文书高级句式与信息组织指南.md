# 申请文书高级句式与信息组织指南

> 给 PS / SOP / 英文申请文书生成 AI 的语言参考。依据《托福雅思必备语法第三章：复杂句型》15 集本地转写整理，日期为 2026-10-19。
>
> 目标：让句式跟随论证关系变化，减少“经历 → These experiences/findings → 抽象感悟”的重复。复杂度不作为写作目标。

## 0. 使用约定：先读这一节

这是一份写作参考资料，可以作为现有 skill 的 reference 使用。它不替代申请人的事实材料、学校题目、字数要求或现有 skill 的事实核验流程。

文中区分三类内容：

- **课程提炼**：课程明确讲到的语法机制，例如从句位置、定语从句、分词、条件句。保留分集、时间和证据编号。
- **文书迁移**：用这些机制组织申请材料的编辑方法。具体主语接力、段落节奏、句式重复诊断等属于本指南的编辑补充，不冒充课程原话。
- **教学示例**：所有申请文书英文例句均为虚构素材上的原创示范。不得把示例中的项目、实验、指标、认识变化或职业目标写成任何申请人的事实。

课程依据是机器转写，并非逐句校听的官方讲义。详细摘录、文件指纹与校核说明见同目录《课程依据与转写校核记录.md》。本指南已避开明显转写错误，且对若干简化规则加上使用边界。

## 1. 要解决的是承接方式重复

用户反馈：

> 句式有点单一，感觉语言逻辑一直都是用 these 把前文经历概括成一个抽象的对象，然后再引出下一层论证……多了就模板了。有时候可以调整信息的先后顺序让句式活起来……表达原因的时候也是有类似的单一感觉。

典型重复路径：

```text
I completed X.
These experiences strengthened my interest in Y.
I then worked on Z.
These insights deepened my understanding of W.
These findings motivated me to pursue further study.
```

问题同时出在三个层面：

1. **主语重复**：具体动作总由 I 承担，反思总由 these + 抽象名词承担。
2. **论证重复**：每件事都导向“增强兴趣 / 加深理解”，很少说明究竟哪个问题变得清楚、哪个判断被修正。
3. **信息顺序重复**：总先交代完整经历，再总结，再宣布动机。结果、矛盾、条件和行动理由从不成为句子的入口。

把 `These experiences` 换成 `This exposure`、`Such insights` 或 `This journey`，上述路径仍然相同。每句结尾加 `, which ...` 也可能复制同一问题。

有效修改通常先回答：**前文留下了哪个具体对象、矛盾或问题？下一句对它做了什么新判断或行动？** 然后再选句法。

`These` 本身不禁用。例如前文明确列出了几项部署限制，后文讨论这些限制共同造成的取舍，`These constraints ...` 可以是精确承接。需要检查的是指代清晰度、信息增量和相邻段落是否反复使用同一个动作。

## 3. 二十类可迁移句式

以下骨架是可观察的结构，不是必须填满的模板。每个例句独立示范；除第 5 节的统一案例外，不要拼接成同一个申请人的经历。

### A01｜让具体问题成为下一句的主语

**性质：文书迁移。** 不是课程直接给出的 PS 写作规则。

**用途**：前文已经出现一个可命名的问题，下一句继续分析它。

**骨架**：`[具体结果 / 对象 / 限制] + [具有实义的谓语] + ...`

> The model's errors during holiday periods remained hidden in its overall accuracy score.

接下来可以直接分析误差；不必先写 `These findings deepened my understanding of model evaluation.`。这里新增的是“整体指标遮蔽了哪类误差”，而非一句更漂亮的自我评价。

**边界**：前文必须支持所写的结果。把 `These findings` 换成 `The discrepancy`，随后仍只写 `deepened my understanding`，改进有限。让 `I` 继续做行动主语完全可以。

**课程基础**：P04 01:24–02:16 的修饰对象定位、P09 01:42–02:44 的信息位置；具体主语接力属于编辑补充。证据 S04、S10。

### A02｜用下一步行动承接，省掉多余感悟句

**性质：文书迁移。**

**用途**：前文已解释困难，下一句需要推进叙事。

**骨架**：`I + [检查 / 比较 / 修订 / 追踪等具体动作] + [对象].`

> I examined the errors week by week and checked which dates were represented in the training data.

比 `These observations encouraged me to conduct further analysis` 更直接地交代了分析内容。

**边界**：只写申请人确实做过的动作；原材料只有“注意到误差”时，不能补成“逐周排查”。如果行动理由尚不清楚，应补出有依据的理由，而非一律删除解释。

**课程基础**：P01 09:07–10:10 的分句关系；行动接力是编辑补充。证据 S01。

### A03｜情境前置：When / While / As ...

**性质：课程提炼 + 文书迁移。**

**用途**：让读者先知道问题出现在什么任务或观察过程中。

**骨架**：`When / While + [情境], I + [主要行动 / 发现].`

> When I examined the forecasts week by week, I found that the model consistently underestimated holiday demand.

**信息重心**：检查过程是背景，具体发现落在主句。也可把发现先说，再后置情境；选择取决于前文已知什么。

**边界**：`when` 不自动证明因果。`as` 可能被理解为时间或原因，含义不清时用更明确的词。避免每段都用 `During my internship` 或 `While working on ...` 起句。

**来源**：P09 01:42–02:44；S10。

### A04｜让步：Although ... , ...

**性质：课程提炼 + 文书迁移。**

**用途**：把“已有优势”和“仍未解决的问题”放在同一句，避免每段只堆成绩。

**骨架**：`Although + [已成立的事实], [仍需强调的事实].`

> Although the model had the lower overall error, it still missed the holiday peaks.

**信息重心**：主句承载下一段需要处理的问题。若真正要突出成果，可以调整两部分的地位，而非固定把不足放在后面。

**边界**：两项事实间应存在预期落差。`although` 后不再机械加 `but`。`even though` 通常承认事实，`even if` 通常保留假设条件，不能随意互换。

**来源**：P09 12:20–14:06；S12。语义边界参见 [Cambridge：Even though / even if](https://dictionary.cambridge.org/grammar/british-grammar/comparatives)。

### A05｜原因前置或后置：Because ...

**性质：课程提炼 + 文书迁移。**

**用途**：改变原因与行动的出场顺序；不必把所有原因都压成 `This led me to ...`。

**两种骨架**：

> Because the training data excluded holiday periods, I questioned whether the evaluation reflected the intended use of the model.

> I questioned whether the evaluation reflected the intended use of the model because the training data excluded holiday periods.

第一句先搭前提，第二句先给出判断。材料支持同一因果关系时，信息重心可以不同。

**边界**：这两个示例都断言该事实是提问的理由，需要素材支持。观察到 A 和 B 同时出现，不足以写成 A caused B。不要为了避免 `because` 而轮换 `since/as`；它们可能引入歧义。

**来源**：P09 09:03–10:29、01:42–02:44；P10 00:19–03:00；S10、S11、S15。

### A06｜用已知前提解释取舍：Given that ...

**性质：课程提炼 + 文书迁移。**

**用途**：解释为什么在特定限制下采用某个方法。

**骨架**：`Given that + [可核实前提], I + [决策].`

> Given that the sample contained few observations from small firms, I treated the subgroup estimates cautiously.

**另一种压缩**：`Because of + 名词短语, ...`，如 `Because of the limited sample, ...`。完整从句能更清楚地说明“样本的哪一方面有限”。

**边界**：`given that` 把前提当作成立的事实，不能接未经验证的猜测。`in that` 常用于说明“具体在何种意义上 / 哪一点上”，不作为所有 `because` 的替换词。避免堆积 `the fact that`。

**来源**：P09 09:35–10:29；P10 00:19–03:00；S11、S15。

### A07｜目的与方法：To ... / so that ...

**性质：课程提炼 + 文书迁移。**

**用途**：让目的先于行动出现，或明确不同执行者之间的关系。

> To assess performance across the full year, I evaluated the forecasts separately for holiday and non-holiday periods.

> I documented the coding rules so that other team members could apply them consistently.

第一句把检查目的放在开头；第二句保留 `other team members`，明确谁将使用规则。

**边界**：目的不等于成果。第二句不能直接改成“从而确保团队始终一致”。`I documented ... to apply ...` 可能被理解成由 I 执行 apply，不能在不同执行者之间机械缩减。`so ... that` 的程度—结果结构也不同于这里的目的表达。

**来源**：P09 19:13–21:42；P10 06:18–08:17；S14、S16。

### A08｜对照：Whereas ... / ... , whereas ...

**性质：课程提炼 + 文书迁移。**

**用途**：比较两种方法、任务或评价维度，让专业判断替代空泛感悟。

> Model A performed better on ordinary weeks, whereas Model B captured the holiday peaks more accurately.

**信息重心**：先建立比较对象，再在同一维度上呈现差别。它可以自然引出“如何权衡不同表现”的问题。

**边界**：两个比较结论都要有证据。不能从“做过两个项目”自动推出两个行业的普遍差异。`whereas` 的对照关系与 `although` 的让步关系不总相同。

**来源**：P09 14:07–14:32；S13。

### A09｜定语从句：让抽象名词具体起来

**性质：课程提炼 + 文书迁移。**

**用途**：说清是哪一种问题、制度、工具或使用条件，而非增加空洞修饰。

> I became interested in evaluation methods that account for shifts in demand over time.

更正式的关系表达在确有需要时可以使用：

> I examined the conditions under which the model's predictions became unreliable.

> I worked with a dataset whose coverage varied substantially across regions.

**边界**：`under which` 中的介词由语义和搭配决定，不能一律用 `in which`。`whose` 可以表达无生命对象的所属关系。修饰从句应靠近其对象；过长修饰使主语与谓语分离时，拆句更清楚。

**来源**：P04 01:24–02:16；P06 00:25–05:10、16:19–17:20；S04、S05、S06。

### A10｜后置分词：压缩背景修饰

**性质：课程提炼 + 文书迁移。**

**用途**：让已明确的背景少占篇幅，把谓语位置留给主要行动。

> The interviews conducted during the pilot informed the revised questionnaire.

> The system processing the incoming requests recorded each failed transaction.

这里的 `conducted ...` 和 `processing ...` 修饰前面的名词，不是新的主要谓语。

**边界**：不能只看主动或被动就删除关系代词和动词；情态、时态、否定和适用范围可能改变。例如 `a system that can detect errors` 缩成 `a system detecting errors`，会丢失“能力”含义。`conducted` 本身也不单独编码过去时间。

**来源**：P08 00:19–02:15；S09。

### A11｜非限定性定语从句：安放次要信息

**性质：课程提炼 + 文书迁移。**

**用途**：补充一个已经明确的对象，让主要动作留在主句。

> The survey, which covered three regions, gave us a basis for comparing local responses.

**边界**：三地范围必须有依据；从句也必须确实属于次要信息。非限定性从句不使用 `that`。删去补充从句后通常仍能识别对象，但信息会减少。

整句指代的 `, which ...` 语法上可以使用；若每个经历都以 `, which strengthened my interest ...` 收尾，仍是同一种承接。`which` 指向一个名词还是整件事不清楚时，应明确对象或另起一句。

**来源**：P07 00:00–02:22、03:57–06:17；S07、S08。参见 [Cambridge：整句关系从句](https://dictionary.cambridge.org/grammar/british-grammar/relative-clauses-referring-to-a-whole-sentence)。

### A12｜分词状语：背景动作退居次位

**性质：课程提炼 + 文书迁移。**

**用途**：同一执行者有背景动作和主要动作，需要压缩前者。

> Working with the raw survey responses, I noticed inconsistencies in how participants interpreted the scale.

> When reviewing the codebook, I checked whether each category had a consistent definition.

第二句保留 `when`，使时间关系更明确；没有连接词的 `-ing` 结构有时会让读者在时间、原因和伴随之间猜测。

**边界**：句首常规分词结构的逻辑主语应与主句主语一致。不要写 `Reviewing the responses, several inconsistencies became apparent`，否则字面上像是 inconsistencies 在 review。连续多句 `Working / Analysing / Reflecting ... , I ...` 同样会形成模板。

**来源**：P10 03:19–10:30；S16。参见 [British Council：Participle clauses](https://learnenglish.britishcouncil.org/grammar/c1-grammar/participle-clauses)。

### A13｜完成分词：Having done ...

**性质：课程提炼 + 文书迁移。** 课程出现完成被动分词，下面扩展示范完成主动分词。

**用途**：确实要突出“先完成 A，再开展 B”。

> Having checked the coding rules against the original responses, I revised the categories used in the analysis.

**边界**：这句话新增了明确的动作先后和完成状态，材料必须支持。`Having participated in ...` 往往只拉长背景，不必优先使用。需要保留时间关系时，`After checking ...` 或两个完整句子也可以更自然。

**来源**：P10 15:56–17:10 的 `having been heated` 及动作逻辑；S17。完成主动形式是迁移扩展，另参 [British Council：分词从句](https://learnenglish.britishcouncil.org/grammar/c1-grammar/participle-clauses)。

### A14｜信息焦点：What ... was ...

**性质：名词性从句基础上的文书迁移补充。** 不声称课程系统讲解过伪分裂句。

**用途**：前文已建立一个待解释对象，现在需要突出具体发现。

> What the aggregate score concealed was the model's failure during holiday periods.

焦点落在系词后的具体内容。通常直接写 `The aggregate score concealed the model's failure during holiday periods` 也很好；只有确实需要聚焦时，才保留较重的结构。

**边界**：`What struck me was ...`、`What I learned was ...` 不能成为新的通用开头。`It was X that ...` 同样带强调，不因“显得高级”而添加。特别是 `It was only when ... that ...`，还可能加入原材料没有的“只有在那时才”含义。

**课程基础**：P12 09:37–10:18 的 what；S20。焦点用法校核参见 [Cambridge：Cleft sentences](https://dictionary.cambridge.org/grammar/british-grammar/cleft-sentences-it-was-in-)。

### A15｜问题化：whether / how / why ...

**性质：课程提炼 + 文书迁移。**

**用途**：把 `I developed an interest in ...` 落到一个可表达、可研究的问题上。

> I wanted to understand whether the result would hold under a different sampling procedure.

> I now want to learn how to evaluate forecasting models when the available data cover only part of the demand cycle.

`whether` 表达尚未确定的真伪，`how` 表达方法或机制，`why` 寻找解释。选择应由真实问题决定。

**边界**：不要把一个疑问改成已验证结论。嵌入从句使用陈述语序，例如 `how the system works`，而非 `how does the system work`。`whether` 在介词后、某些主语或表语位置比 `if` 更适用。

**来源**：P12 22:40–25:30；P14 07:59–08:49；P15 00:00–00:40；S21、S23、S25。

### A16｜直接展开问题内容：The difficulty was that ...

**性质：课程提炼 + 文书迁移。**

**用途**：需要准确说明困难、限制、假设或待回答的问题是什么。

> The difficulty was that the available data contained no observations from holiday periods.

> I questioned the assumption that a lower average error implied better performance throughout the year.

前一句把问题内容放在表语位置；后一句把假设内容放在名词后的 that 从句中。`that` 在内容从句中不代替名词成分。

**边界**：不能因为存在 `the fact that`、`the realization that` 就保留一个冗长名词包装。第二句要求申请人确实提出过这一质疑；不要替每个学生制造方法论反思。不是每段都要以 `The challenge was that ...` 起句。

**来源**：P12 00:00–02:40；P15 00:00–00:40、02:40–04:35；S19、S25、S26。

### A17｜后置长判断：It ... that ... / I found it ... to ...

**性质：课程提炼 + 文书迁移。**

**用途**：避免很长的从句挤在主语位置；或表达某项任务为何困难。

> It remained unclear whether the difference came from the model design or the data coverage.

> I found it difficult to compare the estimates because the two reports used different definitions of employment.

**边界**：`it` 是形式成分，不是用来模糊前文指代的万能词。`It is evident that ...` 会增加确定性；`It is widely acknowledged that ...` 会引入外部共识主张，均需证据。`It dawned on me ...` 带突然领悟的叙事，不应凭空添加。形式宾语与不定式的组合是对课程讲解的常用迁移。

**来源**：P13 00:18–04:28；P14 18:29–19:21；S22、S24。

### A18｜条件与反事实：If ...

**性质：课程提炼 + 文书迁移。**

**用途**：给方法选择或判断增加适用条件。

> If the model is intended for peak-season planning, its performance during holiday periods needs separate evaluation.

这里提出评价原则，并不声称申请人已完成相关验证。

过去反事实形式只在有真实分析依据时考虑：

> If I had relied on the overall score alone, I might have overlooked the holiday-period errors.

**边界**：第二句要求真实过程与该假设有可解释关系；`might have overlooked` 不等同于 `would have overlooked`。不要用反事实制造险些失败、克服困难或挽救项目的情节。一般未来计划不必写成虚拟语气。

**来源**：P11 04:25–07:12；S18。

### A19｜平行并列：让两项内容站在同一层

**性质：课程提炼 + 文书迁移。**

**用途**：两项实际动作或考察维度需要并列，而非人为制造“经历 → 感悟”。

> I compared the forecasts across models and examined the errors across periods.

> The evaluation considered both average accuracy and performance during holiday periods.

`not only ... but also ...` 在确有递进时可用，但不必优先于普通 `and`。

**边界**：两端保持语法平行和逻辑层级一致。句首 `Not only did I ...` 要处理倒装，且语气较重。不要把“使用了方法”和“成为优秀领导者”包装成同层结果；后者需要独立证据。

**来源**：P01 09:07–10:10、18:16–19:10；S01、S02。

### A20｜短句与标点：让关键判断落地

**性质：课程提炼 + 文书迁移。**

**用途**：前面已有方法细节或长句，接下来需要一个清楚的判断。

> The overall score concealed the seasonal errors. I needed to examine performance across the year.

也可以在确有转折时写：

> The model performed well overall; however, its holiday forecasts remained unreliable.

**边界**：`however` 和 `therefore` 不能只靠两边的逗号把两个独立分句粘起来；用句号或合适的分号。短句必须有内容，不是每段插入 `I wanted to go further`。分号也不作为“高级”的装饰。

**来源**：P03 03:00–05:10；S03。短句节奏属于编辑补充。

## 4. 因果表达先判断关系，再决定写法

用同一组词轮换原因，不能解决逻辑单调。先在内部给当前关系分类：

| 实际关系 | 可用写法 | 必须保留的边界 |
|---|---|---|
| 我为何采取某项行动 | because；原因前置或后置 | 行动理由有材料支持 |
| 为达到什么目的而行动 | to do；so that | 希望达到的效果尚不等于已实现结果 |
| 哪个前提限制了决策 | given that；because of | 不把猜测当成立前提 |
| 观察到了什么结果 | 让结果做主语；直接描述表现 | 不自动推导唯一原因 |
| 发现了哪一个未解问题 | whether / how / why；It remained unclear ... | 保留未知状态 |
| 两个事实形成预期落差 | although；yet；whereas（对照时） | 不凭句式创造矛盾 |
| 某个过程确实促成了变化 | led to；prompted；enabled 等 | 机制与作用强度应有证据 |
| 多种原因中只是一个可能解释 | may reflect；one possible explanation ... | 不升级为 proved / established / caused |

**特别注意**：`revealed`、`demonstrated`、`confirmed`、`made clear` 也会改变论断强度。它们不是 `showed` 的自由同义词。`enabled` 暗示提供了条件，`required` 暗示必要性，`only` 暗示排他条件，都应核对。

### 同一信息如何换入口

假设唯一已确认信息为：“我在检查逐周误差时发现，整体表现较好的模型漏掉了节假日高峰。”

| 需要强调什么 | 局部表达示例 |
|---|---|
| 发现过程 | When I examined the weekly errors, I found that the model missed the holiday peaks. |
| 出乎预期之处 | Although the model performed better overall, it missed the holiday peaks. |
| 待继续分析的对象 | The model's holiday-period errors were obscured by its overall score. |
| 真正值得讨论的焦点 | What the overall score concealed was the model's failure during holiday periods. |
| 精简陈述 | The overall score concealed the model's holiday-period errors. |

这些是不同功能的局部表达，**不是全部等义的替换**。例如 `concealed/obscured` 进一步描述整体指标如何影响可见性，只在材料或上下文支持时使用；不能只凭“漏报高峰”这一事实自动加入。最安全版本仍可直接写“整体表现较好，但漏掉高峰”。

## 5. 完整改写示范：保留事实，改变推进方式

### 5.1 教学用事实包

下列材料全部是虚构示例，不是用户资料：

- F1：在课程项目中，申请人用零售销售数据比较了两个预测模型。
- F2：整体误差较低的模型没有预测好节假日高峰。
- F3：申请人检查逐周误差，并发现训练数据没有覆盖节假日期间。
- F4：这一遗漏是一个可能解释，但申请人无法分离数据覆盖与模型设计各自的影响。
- F5：申请人希望学习如何验证训练数据覆盖不完整时的时间序列预测。

### 5.2 模板感较强的写法

> In a course project, I compared two forecasting models using retail sales data. The model with the lower overall error failed to capture holiday peaks. These results led me to examine the errors week by week. I found that the training data contained no holiday periods. These findings made me consider the omission as a possible explanation, although I could not separate its effect from that of the model design. These experiences motivated me to learn how to validate forecasts when the training data do not cover the full demand cycle.

内容并非全无意义，但三次用指示词概括后再推进，容易让读者先看到文章的加工方式。

### 5.3 按信息关系重组

> The model with the lower overall error still missed the holiday peaks. I had compared it with another model using retail sales data in a course project. When I examined the errors week by week, I found that the training data contained no holiday periods. Although the omission was a plausible explanation, I could not separate its effect from that of the model design. I now want to learn how to validate forecasts when the training data do not cover the full demand cycle.

这里有五个动作：

1. 结果前置，读者立即看到要讨论的矛盾，依据 F2。
2. 背景后补，说明结果来自什么任务，依据 F1。
3. 用时间从句承接真实检查过程，依据 F3。
4. 让步从句保留可能解释与尚未解决的归因，依据 F4。
5. 直接说清学习问题，依据 F5；没有再加一层抽象“热情增长”。

没有增加数字、成绩、独创算法、团队领导、研究结论或学校资源。保留 `plausible` 和 `could not separate`，是为了不把猜测升级为证明。

这不是要求所有文书都“结果前置”。如果前文已经介绍过该模型，第二句可以删去或另行融合；如果课程项目本身是重要起点，也可以先交代背景。结构由上下文和证据职责决定。

### 5.4 同样的机制可以写成果、协作与学术探索

上面的模型案例用来演示因果边界，不意味着每篇文书都要写成“发现失败 → 认识局限 → 需要深造”。下面同样是虚构教学素材：

| 示例事实前提 | 可用表达 | 句式完成的任务 |
|---|---|---|
| 产品项目中，申请人为方便单手操作，把主控件移到拇指可触及的位置；没有用户测试结果 | To make the prototype easier to operate with one hand, I moved the main control within reach of the user's thumb. | 先说明设计目的，再写具体动作；不声称易用性已获验证 |
| 历史课程中，申请人阅读同一作者的公开演讲与私人信件，发现两类文本对改革持不同语气 | Whereas his public speeches presented reform as inevitable, his private letters expressed reservations about its likely effects. | 用具体文本对照承载学术观察，不再补一句“加深了理解” |
| 商科团队项目中，申请人确实把访谈主题整理成采购清单，并在之后会议中解释各项依据 | Having translated the interview themes into a purchasing checklist, I explained the evidence behind each item at the next team meeting. | 压缩先完成的工作，把沟通与证据解释放在主句 |
| 教学活动最后一节，参与者确实能独立解释先前容易混淆的两类论证；没有因果实验 | By the final session, participants could distinguish the two types of argument without consulting the worksheet. | 直接呈现有依据的学习成果；不额外宣称是哪一个教学环节造成了进步 |

材料允许时可以直接写成功、清楚的专业判断和有效协作。复杂句承担多少工作，取决于这些事实之间的关系。

## 6. 给生成 AI 的使用流程

### 6.1 生成或修改前：建立最小事实底稿

内部记录每段需要的内容即可，不把下面的标签写进正文：

```text
已确认事实：具体对象、行动、结果、时间、角色。
个人判断：资料是否支持；是当时判断还是现在的反思。
未解问题：哪些仍不确定。
未来意向：按当前任务和已有授权处理。
本段职责：这一段为何需要出现在这篇申请文书中。
```

如果原文只有 `I gained valuable insights`，没有任何具体内容，不要通过造一个具体洞察来“升级语言”。先从授权材料寻找可用信息；仍无依据时，压缩、删除或按现有工作流处理缺口。

### 6.2 每个衔接点只选一个主动作

先判断要继续行动、解释理由、限定范围、对照结果、提出问题，还是补充背景。再选能够表达该关系的最轻结构。无需向每一句加入从句。

实用顺序：

1. 尝试让下一句直接接住具体对象或行动。
2. 需要明确时间、让步、条件、原因时，使用对应完整从句。
3. 主语、时态和信息地位清楚后，才考虑分词压缩。
4. 确有强调需要时，再考虑 what 焦点结构或分裂句。

### 6.3 先检查重复，再做局部调整

逐段查看三个序列：

- **主语序列**：I / I / These findings / I / These experiences ...
- **句首序列**：During / Through / Having / What ...
- **论证动作序列**：做项目 → 获得理解 → 增加兴趣 → 想读硕士。

以下是人工复核信号，不是自动判错配额：

- 相邻几段反复以 `These experiences/insights/findings ...` 推出动机。
- 连续多句用不同词面执行同一动作，例如 led me / prompted me / inspired me。
- 两个相邻段落都以 `What I learned ...` 或 `Having done ...` 开始。
- 每个经历段都在同一位置出现一个“认识到局限”的句子。
- 多个长句都在末尾附加 `, which ...` 或 `, thereby ...`。

出现信号时，先看内容是否重复。只有当一段确有不同职责时，才用不同句式表达它。若两句在重复同一判断，删除其中一句通常优于改写。

### 6.4 改写后执行语义检查

| 要检查的维度 | 常见无意变化 |
|---|---|
| 执行者与职责 | 我参与 → 我主导；团队结果 → 个人成果 |
| 时间与顺序 | A 与 B 并存 → 完成 A 后才做 B |
| 因果强度 | 可能相关 → A 导致 B |
| 完成状态 | 为了实现 → 已经实现 |
| 适用范围 | 部分样本有效 → 普遍有效 |
| 认知与感受 | 提出一个问题 → 突然顿悟 / 终身热爱 |
| 对照关系 | 两种活动不同 → 某种方法本质上优越 |
| 条件与事实 | 可能发生 → 确定会发生；已发生 → 假设发生 |
| 语法指向 | 分词、which 或代词的对象改变 |

任一维度发生无依据变化，应恢复原意。即使新句更流畅，也不优先采用。

### 6.5 保留自然节奏

成熟文书可以大量使用普通主谓句。短句负责明确判断，较长句负责展开限定和关系。没有“每段必须两种高级句式”或“全文必须一个倒装”的要求。

不要刻意把所有 I 都换成无生命主语；申请文书需要让读者看见申请人做了什么。也不要把所有反思写成不确定性和失败，是否表达成绩、困惑、判断或目标，由真实材料决定。

## 7. 不优先套用的“高级句”

| 结构 | 有效场景 | 常见代价 |
|---|---|---|
| Not only did I ..., but I also ... | 确实要强调第二项递进事实 | 语气重；可能只是在夸大两件普通动作 |
| It was only when ... that ... | 确有被强调的时间 / 条件转折 | 凭空加入唯一性或顿悟 |
| Had I ..., I would have ... | 有依据的过去反事实分析 | 容易制造戏剧化经历 |
| Difficult as ... may be, ... | 确实需要承认困难并强调主句 | 容易成为展示语法的装饰 |
| So ... that ... / such ... that ... | 真实程度与结果关系需要突出 | 容易把普通表现写成夸张结果 |
| , thereby ensuring ... | 行动机制和确定结果均有证据 | 把目的、潜在帮助升级为确保 |
| It is widely acknowledged that ... | 有必要引用可靠外部共识 | 泛泛开篇，且引入需核实的主张 |

这些结构不禁用；它们比普通主谓句承担更多含义，因此需要更多语境支持。表中部分结构是编辑补充，不主张全都来自本课程。

## 8. 可直接复制给现有文书 AI 的指令

```text
请将《申请文书高级句式与信息组织指南》作为语言与信息组织参考使用。

目标是减少重复的论证路径，并让句式表达具体关系。事实准确、任务要求、申请人声音与论证清楚优先于复杂句数量。

1. 先按现有 skill 读取并核实申请人的资料；指南中的例句全部是教学示例，不得作为申请人事实或自动生成的动机来源。
2. 检查“经历 → these/this/such + 抽象名词 → 加深理解/增强兴趣”的重复。不要仅替换指示词、抽象名词或动机动词。
3. 对每处需修改的衔接，先确定主要关系：继续行动、具体对象接力、时间、原因、目的、让步、对照、条件、范围限定或未解问题。
4. 由信息焦点决定原因、背景、结果和判断的顺序。允许结果前置、背景后补，也保留上下文需要的普通顺序。
5. 优先直接陈述真实行动、具体问题和明确判断。需要时再使用定语从句、状语从句、名词性从句或分词；焦点句、倒装和反事实只在含义确有需要时使用。
6. 不设高级句配额，不随机打乱长短句，不强行减少 I 或禁用 These。警惕把每段都改成 What ... / Having ... / Although ... / , which ...。
7. 改写后核对事实、执行者、时间、完成状态、适用范围、情态和因果强度。保留原有未知状态，不把目的写成成果，也不补写顿悟、失败或领导作用。
8. 核对分词逻辑主语、关系从句指向、嵌入从句语序、标点及动词搭配；必要时退回完整从句或拆句。
9. 如果问题来自缺少具体内容或段落职责重复，优先修正内容选择与论证；句式库不能替代事实和思考。
10. 最终正文保持自然文章体，不出现句式编号、语法标签、来源编号或教学说明。用户需要解释时，另附最关键的改动及其信息组织理由。

需要输出改写说明时，可选用：原句｜主要问题｜改写｜事实与逻辑是否保持。无须逐句报告所有修改。
```

如果要接入 skill，可把本文件放入该 skill 的 `references/`，在写作和语言复核步骤中引用上面的指令；无需每次加载 15 集完整转写。对具体 skill 文件的实际修改，应在明确目标文件后实施。

## 9. 采用前检查

- [ ] 能说明修改后读者先看见了什么、哪部分得到强调。
- [ ] 每个反思句指出具体认识或问题，而非仅宣告“理解加深”。
- [ ] 仍能辨认申请人自己的行动与判断。
- [ ] 相邻段落没有换一种句式重复相同的经历总结路径。
- [ ] 英文例句、课程知识和用户事实严格分开。
- [ ] 词汇与句法没有提高事实的确定性、成果等级或个人贡献。
- [ ] 简单句在清楚表达时得到保留。

没有通过的句子应继续改写、拆分或删减，不以“语法更复杂”作为通过依据。
