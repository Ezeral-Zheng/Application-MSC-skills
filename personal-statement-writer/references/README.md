# Personal Statement Writer References

把 PS/SOP 相关参考文档放在这里，例如：

- PS/SOP 范文
- 学校或项目文书题目
- 项目匹配材料
- 风格样例与禁用表达

使用时只读取和当前任务相关的文件。

`申请文书高级句式与信息组织指南.md` 是 PS 写作与修改的通用必读语言参考，保留方法与示例。其课程原始转写和校核记录为本地来源，未随仓库分发；需要重新核查课程证据时须另行提供来源，不能假定这些文件已存在。常规写作无需加载转写或联网访问其中的语法链接。

修改 skill 通过相邻 `personal-statement-writer/references/` 引用此文件；独立审稿使用自身的五维/八维标准及信息组织复核规则，不读取写作过程或写作 skill。
