# 推荐人身份一致性检查表

写作或审查推荐信时，用此表检查推荐人身份、课程和观察范围是否一致。

## 基础身份

- 推荐人姓名是否与 `Recommender_Info` 一致。
- 推荐人职位、院系、学校是否与资料一致。
- 推荐人与学生关系是否有资料依据，例如授课教师、课程导师、项目指导教师。

## 课程与交集

- 推荐信中的课程是否属于当前推荐人。
- 课程成绩、作业、presentation、team project 是否来自该推荐人的课程或可观察范围。
- 不得把另一位推荐人的课程、评价或项目写入当前推荐信。

## 观察范围

- 推荐人评价的能力应能通过课程、作业、课堂、沟通或项目观察得出。
- 如果资料只显示课程关系，不要写成长期科研指导或密切合作。
- 如果推荐人不能直接观察实习或校外经历，只能作为背景补充，不应写成推荐人的直接评价。

## 双信差异

- 两封推荐信的推荐人自我介绍不能同等篇幅、同等句式重复。
- 两封推荐信的核心例证、能力标签和结尾推荐语应明显区分。
- 如果资料不足以支撑差异化，标记为 `Blocked`，不要用空泛语言硬凑。
