# 推荐信固定段功能库

固定段只保留“功能”，不得照搬 reference 原句。每次写作都要根据学生、推荐人、目标专业和推荐信结构改写。

## 开头段功能

- 表明推荐意图：推荐当前学生申请研究生项目。
- 说明推荐人身份：职位、院校、课程或教学关系。
- 说明观察基础：课程、课堂互动、作业、项目、presentation、讨论或评价场景。
- 给出总体评价：学术能力、学习态度、专业潜力或适配度。

## 关系说明段功能

- 说明推荐人教授过的课程或指导过的任务。
- 说明学生在这些课程中的表现依据。
- 避免夸大亲密程度；如果只有课程关系，不写长期指导或密切科研合作。

## 结尾段功能

- 总结学生适合继续深造的理由。
- 重申推荐态度。
- 如目标项目未知，使用 `postgraduate program` 或 `graduate studies`。
- 不编造目标学校、项目特色或导师匹配。

## 签名段功能

- 推荐人姓名、职位、机构。
- 如果资料中没有邮箱或联系方式，不自行补写。
