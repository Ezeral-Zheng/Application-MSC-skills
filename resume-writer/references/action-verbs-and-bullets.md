# Resume Action Verbs and Bullet Rules

## Action Verbs

- Analysis: analyzed, evaluated, interpreted, compared, assessed, identified
- Data and Modeling: built, cleaned, modeled, forecasted, validated, visualized
- Research: reviewed, synthesized, examined, investigated, tested, documented
- Business: developed, proposed, benchmarked, optimized, coordinated, presented
- Engineering: implemented, designed, debugged, integrated, automated, improved

## Bullet Pattern

Use one of these patterns only when every fact is supported by source material:

```text
- Action + object + method/tool + purpose/result.
- Action + problem/context + approach + supported outcome.
- Action + dataset/case/course task + analytical frame + finding.
```

## Avoid

- Do not start bullets with weak phrases such as `Responsible for` unless the source only supports responsibility and not action.
- Do not invent metrics to make bullets stronger.
- Do not write long narrative paragraphs.
- Do not use PS language such as motivation, personal growth, or future aspiration.
