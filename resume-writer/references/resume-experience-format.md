# Resume-Experience Format Reference

Use this format when converting Course_Info projects into resume experience entries.

```md
## Project Experience

**Project Name** | *Course Project*
*Role if supported*
Date - Date if supported

- Action-driven bullet supported by Course_Info.
- Action-driven bullet supported by Course_Info.

## 未纳入项目

- Project Name：缺少具体行动、方法或结果，暂不写入正文。

## 资料依据

- `学生名/Course_Info/xxx.md`
```

## Rules

- Omit role or date if source material does not support it.
- Put incomplete projects in `未纳入项目`; do not fill gaps with generic claims.
- Each bullet must be traceable to Course_Info.
- Keep 2-4 bullets per project.
